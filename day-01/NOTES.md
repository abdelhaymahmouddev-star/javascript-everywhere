# Day 01 Notes

## What Node.js is and how it's different from a browser

Node.js is a JavaScript runtime that allows JavaScript to run outside the browser.

A browser provides APIs such as the DOM and window object, while Node.js provides APIs for working with the file system, processes, and the server.

## What npm is for

npm is the package manager for Node.js.

It is used to install, manage, update, and share JavaScript packages and dependencies.

## The difference between Git and GitHub

Git is a version control system that runs on my computer and tracks changes in my project.

GitHub is an online platform where I can store Git repositories, collaborate with others, and share my code.

## Commands I learned

- `git init` — creates a new Git repository.
- `git add .` — stages all changed files.
- `git commit -m "message"` — saves the staged changes with a message.
- `git branch -M main` — renames the current branch to main.
- `git remote add origin URL` — connects the local repository to a GitHub repository.
- `git push -u origin main` — uploads the local main branch to GitHub.
- `git status` — shows the current state of the Git repository.
- `git log` — shows the commit history.
- `node filename.js` — runs a JavaScript file using Node.js.
